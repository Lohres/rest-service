# Code Review Policy

## Mindestpruefungen

- Funktionale Korrektheit
- Seiteneffekte und Regressionen
- Testabdeckung fuer geaenderte Logik
- Sicherheit und Input-Validierung
- Lesbarkeit und Wartbarkeit

## Erwartete PR-Inhalte

- Problem und Ziel der Aenderung
- Technischer Ansatz
- Verifikation (Tests/Checks)
- Risiken und Rollback-Hinweis
